# STM32 Learning

This repository documents my journey learning STM32 embedded systems development using the STM32 NUCLEO-F446RE development board.

The goal is to build practical embedded programming skills through structured lessons, hardware experiments, firmware projects, engineering documentation, and progressively more advanced STM32 applications.

---

# Objectives

- Learn embedded C programming
- Understand STM32 microcontroller architecture
- Configure peripherals using STM32CubeMX
- Develop and debug firmware using STM32CubeIDE
- Build practical hardware projects
- Learn professional Git and GitHub workflows
- Create an embedded systems engineering portfolio

---

# Hardware

- STM32 NUCLEO-F446RE development board
- Breadboards
- Jumper wires
- LEDs
- Resistors
- Pushbuttons
- Potentiometers
- USB-to-serial adapter
- Soldering equipment
- Basic electronic components

Additional sensors and communication modules may be added as the repository develops.
